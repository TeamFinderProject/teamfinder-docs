# TeamFinder

**TeamFinder** — веб-сервис для поиска участников и формирования команд для pet-проектов, хакатонов и учебных проектов.

Пользователь создаёт профиль, указывает свои навыки и интересы, после чего может находить подходящие проекты и откликаться на интересующие роли.

Создатель проекта публикует описание, указывает необходимые роли, требуемые навыки и количество свободных мест. Он может просматривать заявки кандидатов, принимать или отклонять их и таким образом формировать команду.

После формирования команды проект проходит через несколько этапов жизненного цикла: **набор участников**, **работа над проектом** и **завершение**. Для проекта также могут быть заданы контрольные этапы, позволяющие фиксировать основные результаты работы команды.

## Основные возможности

- регистрация и авторизация пользователей;
- создание и редактирование профиля;
- указание навыков и интересов;
- создание и публикация проектов;
- добавление необходимых ролей в проект;
- указание количества мест и требуемых навыков для роли;
- поиск и фильтрация проектов;
- отправка заявки на участие в проекте;
- просмотр и рассмотрение заявок;
- принятие или отклонение кандидатов;
- формирование состава команды;
- управление жизненным циклом проекта;
- создание и отслеживание контрольных этапов проекта.

## Основной сценарий

1. Пользователь регистрируется и заполняет профиль.
2. Создатель публикует проект и указывает необходимые роли.
3. Другие пользователи находят проект и подают заявки.
4. Владелец проекта рассматривает заявки и формирует команду.
5. После завершения набора проект переходит в работу.
6. Команда проходит контрольные этапы проекта.
7. После выполнения поставленных целей проект отмечается завершённым.

## Возможное развитие

В дальнейшем сервис может быть расширен:

- системой уведомлений;
- интеграцией с внешними сервисами для общения команды;
- системой репутации участников;
- рекомендациями проектов на основе навыков пользователя;
- дополнительными инструментами для организации работы команды.
