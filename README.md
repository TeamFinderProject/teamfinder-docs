# TeamFinder

TeamFinder — веб-сервис для поиска команды на pet-проекты, хакатоны и учебные проекты.

Пользователь создаёт профиль, указывает свои навыки и интересы, после чего может находить подходящие проекты и откликаться на нужные роли. Создатель проекта указывает, какие специалисты ему нужны, рассматривает заявки и формирует команду.

## Основные возможности

- создание профиля пользователя;
- указание навыков и интересов;
- создание проектов;
- добавление необходимых ролей в проект;
- поиск и фильтрация проектов;
- отправка заявок на участие;
- принятие или отклонение заявок;
- формирование команды проекта.
